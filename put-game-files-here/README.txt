Pillars of Eternity Mobile - put your game files here
=====================================================

Put these things into this folder (any file names are fine):

  1. Pillars of Eternity: Complete Edition, base game   title 0100D6200E130000 v0        NSP, NSZ, XCI or XCZ
  2. its update 2.60.00                                  title 0100D6200E130800 v393216   NSP, NSZ, XCI or XCZ
                                                         (an XCI that already contains this update counts as both 1 and 2)
  3. prod.keys                                           the keys of YOUR OWN console (dumped with Lockpick_RCM)

Only this update (v393216, 2.60.00) is supported: the port is made for its exact game code.

Then run setup:
  Windows:        double-click setup.bat (one folder up)
  Linux / macOS:  ./setup.sh  (one folder up)

It asks which phone the game is for (Adreno / Mali, PowerVR, Xclipse / not sure) and prepares
work/PillarsOfEternityMobile (16 to 28 GB depending on that answer); copy that folder to the phone as
Download/PillarsOfEternityMobile. During setup about 90 GB must be free on the drive of this folder; a full run takes
20 to 40 minutes.

Your files are only read; nothing is changed or uploaded (setup makes hard links to them in its work folder). Everything
in this folder except this README is ignored by Git. Dump the game and the keys from a Switch you own: they are never
shared by this project.

Pillars of Eternity Mobile - положите сюда файлы игры
=====================================================

Положите в эту папку (имена файлов любые):

  1. Pillars of Eternity: Complete Edition, базовая игра   title 0100D6200E130000 v0        NSP, NSZ, XCI или XCZ
  2. обновление 2.60.00                                    title 0100D6200E130800 v393216   NSP, NSZ, XCI или XCZ
                                                           (XCI, в котором уже есть это обновление, считается сразу за 1 и 2)
  3. prod.keys                                             ключи ВАШЕЙ консоли (снятые через Lockpick_RCM)

Поддерживается только это обновление (v393216, 2.60.00): порт сделан под его код.

Затем запустите установку:
  Windows:        двойной щелчок по setup.bat (на уровень выше)
  Linux / macOS:  ./setup.sh  (на уровень выше)

Установка спросит, для какого телефона игра (Adreno / Mali, PowerVR, Xclipse / не знаю), и подготовит папку
work/PillarsOfEternityMobile (от 16 до 28 ГБ в зависимости от ответа); скопируйте её на телефон как
Download/PillarsOfEternityMobile. Во время установки на диске с этой папкой нужно около 90 ГБ свободного места;
полный проход занимает 20-40 минут.

Файлы только читаются: ничего не меняется и не отправляется (установка делает на них жёсткие ссылки в своей рабочей
папке). Снимайте игру и ключи со своей Switch: проект их никогда не распространяет.
