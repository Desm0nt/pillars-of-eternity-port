# Установка Pillars of Eternity Mobile — по шагам

English version: [INSTALL.md](INSTALL.md).

Pillars of Eternity Mobile запускает на Android-телефоне **вашу собственную копию** Pillars of Eternity: Complete Edition
для Nintendo Switch. В проекте нет файлов игры, и он никогда не раздаёт ни игру, ни ключи консоли: вы снимаете их со
своего Switch. Программа установки на ПК превращает ваш дамп в папку игры (15–28 ГБ в зависимости от набора текстур), вы
копируете её на телефон и ставите приложение.

Установка идёт 20–40 минут (на быстром ПК — 18), плюс время на копирование папки на телефон.

## Что понадобится

**С вашего Switch** (см. шаг 1):

| Что | Подробности |
|---|---|
| Базовая игра Pillars of Eternity: Complete Edition | title id `0100D6200E130000`, с картриджа или из eShop |
| Обновление Pillars of Eternity **v393216** (2.60.00) | title id `0100D6200E130800`. Работает только это обновление (порт сделан под его код, установка это проверяет). Программы дампа обычно пишут его в имя файла, например `...[0100D6200E130800][v393216].nsp`. Дамп картриджа (XCI), в котором это обновление уже есть, считается сразу за оба файла |
| `prod.keys` | ключи **вашей** консоли |

Обе части дополнения The White March входят в Complete Edition — отдельно снимать ничего не нужно.

Игра и обновление могут быть в **NSP, NSZ, XCI или XCZ**. Имена файлов не важны: установка узнаёт их по содержимому.

**ПК** с Windows 10/11 (64-бит). Для Linux / macOS есть `setup.sh` (bash, системный Python 3.12+ с `venv`), но на этих
системах он пока не проверялся.

- около **90 ГБ свободного места** на диске с папкой установки в момент запуска (распаковщик дампа проверяет это и при
  нехватке сразу останавливается). Рабочая папка в пике занимает около 45 ГБ, после установки в `work/` остаётся около
  30 ГБ, а папка для телефона собрана из жёстких ссылок на эти файлы и лишнего места не занимает. Если дампы лежат на
  другом диске, установка сначала копирует их к себе (ещё 14 ГБ для файлов NSZ);
- интернет при первом запуске: установка скачивает недостающее — отдельный Python 3.12 (~15 МБ, только если на ПК нет
  Python 3.12 или новее), пакеты Python (~60 МБ с PyPI), .NET 10 SDK (~300 МБ загрузки, ~800 МБ на диске, только если
  он не установлен) и пакеты NuGet для распаковщика и переводчика шейдеров. Перед каждой загрузкой она спрашивает и
  кладёт всё в `tools\.runtime` внутри своей папки. Следующие запуски работают без интернета. Git для Windows **не** нужен.

**Телефон:**

- Android 8.0 или новее, 64-бит, с Vulkan;
- **рекомендуется Snapdragon с GPU Adreno** (проверено на Snapdragon 8 Gen 3 и 8 Gen 2; для телефонов с Mali / PowerVR / Xclipse
  есть свой набор текстур, см. шаг 4, но они не проверялись);
- **16 ГБ свободно** во внутренней памяти с текстурами BC, 15 ГБ с ASTC, 28 ГБ с обоими наборами;
- USB-кабель (или другой способ скопировать папку на телефон).

## Шаг 1. Снимите файлы игры и ключи со своего Switch

**Самостоятельный дамп.** Нужен Switch, на котором запускается homebrew (как этого добиться, здесь не описано).
1. Установите на Switch игру и обновление v393216.
2. Снимите их через [nxdumptool](https://github.com/DarkMatterCore/nxdumptool): установленная или eShop-копия → *NSP*;
   картридж → *XCI* (отдельно установленное обновление снимается как NSP). Для NSP включите
   **«remove console specific data»** — иначе обновление не прочитается на ПК.
3. Снимите ключи консоли через [Lockpick_RCM](https://github.com/shchmue/Lockpick_RCM). На SD-карте в `switch/` появится
   `prod.keys`.
4. Скопируйте файлы на ПК.

Не скачивайте файлы игры и ключи из интернета и не раздавайте свои.

## Шаг 2. Скачайте установку Pillars of Eternity Mobile

Скачайте этот репозиторий архивом (зелёная кнопка **Code** → **Download ZIP**) или клонируйте и распакуйте на диск, где
хватает места, в **короткий путь** вроде `D:\PoE-setup` (самый длинный путь внутри репозитория — 148 символов, а Windows
плохо переносит пути длиннее 260). Внутри будут `setup.bat`, `setup.sh` и папка `put-game-files-here`.

## Шаг 3. Положите файлы в `put-game-files-here`

```
<папка установки>/
├── setup.bat
├── setup.sh
└── put-game-files-here/
    ├── Pillars of Eternity ... [0100D6200E130000][v0] ... .nsz          (или .nsp / .xci / .xcz — базовая игра)
    ├── Pillars of Eternity ... [0100D6200E130800][v393216] ... .nsz     (обновление)
    └── prod.keys
```

Ваши файлы только читаются: установка делает на них жёсткие ссылки в своей рабочей папке и ничего в них не меняет и
никуда не отправляет.

## Шаг 4. Запустите установку

1. **Дважды щёлкните `setup.bat`.** Если Windows предупреждает о файле из интернета, выберите **Выполнить** (или
   **Подробнее → Выполнить в любом случае**).
2. На вопросы о загрузке отвечайте **Y** и Enter (просто Enter — тоже «да»): отдельный Python (*Download it now?*,
   только если на ПК нет Python 3.12+), пакеты Python (*Install them now?*) и .NET SDK (*Download and install the .NET 10
   SDK there now?*). В систему ничего не ставится, права администратора не нужны.
3. Установка спросит, **на каком телефоне будете играть** (*Which phone(s) will play this?*):

   | Ответ | Набор текстур | Папка на телефоне |
   |---|---|---|
   | 1) Adreno (Qualcomm Snapdragon) | BC, родные текстуры игры; установка быстрее всего | ~16 ГБ |
   | 2) Mali, PowerVR или Samsung Xclipse | ASTC, работает на любом GPU | ~15 ГБ |
   | 3) не знаю / несколько телефонов (Enter) | оба; приложение само выбирает нужный при каждом запуске | ~28 ГБ |

4. **Ждите.** После каждого этапа установка пишет строку с временем. Замер на ПК с 12 потоками и уже установленным .NET SDK:

   | Этап | Заняло |
   |---|---|
   | 1. unpack: распаковка дампов, подготовка программы игры, перевод шейдеров | 4,7 мин (из них 2,7 мин — распаковка NSZ) |
   | 2. image: образ игры для приложения | 1 с |
   | 3. overlay: файлы игры с шейдерами, переписанные под Android | 0,5 мин |
   | 4. astc: набор текстур ASTC (только для ответов 2 и 3) | 12,5 мин |
   | 5. layout: папка для телефона | 2 с |

   Первый запуск с загрузками и медленный ПК — дольше (20–40 минут). Если окно закрылось или ПК выключился — просто
   запустите установку снова: она продолжит с того места, где остановилась.
5. В конце она напишет `DONE`, где готовая папка, команду `adb push` для копирования и что делать дальше.

Вместо `put-game-files-here` можно перетащить файлы прямо на `setup.bat`.

### Не понятно, чего не хватает?

Запустите `setup.bat check` (в терминале в папке установки). Он покажет Python, .NET SDK, найденные дампы и `prod.keys`,
какие этапы готовы и есть ли уже папка для телефона — ничего не меняя.

## Шаг 5. Скопируйте папку игры на телефон

Готовая папка — **`work/PillarsOfEternityMobile`** внутри папки установки.

- **Передача файлов по USB:** подключите телефон, выберите **Передача файлов**, откройте **внутреннюю память** телефона →
  **Download** и скопируйте туда всю папку **`PillarsOfEternityMobile`**. Она большая, копирование займёт время. Должно
  получиться ровно так:

  ```
  Внутренняя память/Download/PillarsOfEternityMobile/RomFS/Data/...
  Внутренняя память/Download/PillarsOfEternityMobile/overlay/Data/...
  Внутренняя память/Download/PillarsOfEternityMobile/overlay-astc/Data/...   (только с набором ASTC)
  Внутренняя память/Download/PillarsOfEternityMobile/game/libf2game.so
  ```

- **adb (отладка по USB):** команду `adb push` установка печатает в конце.

Когда папка уже на телефоне, `work/setup` на ПК можно удалить, чтобы вернуть место (если папка понадобится снова,
установке придётся начать сначала).

## Шаг 6. Установите приложение

Установите `PillarsOfEternity-Mobile-v<версия>-arm64.apk` из
[последнего релиза](https://github.com/Desm0nt/pillars-of-eternity-port/releases/latest) или соберите сами (см. *Building*
в [README](../README.md)). В первый раз Android попросит разрешить установку приложений из браузера или файлового
менеджера.

## Шаг 7. Первый запуск

1. Запустите **Pillars of Eternity Mobile**.
2. В первый раз он покажет страницу с просьбой о **Доступе ко всем файлам** (нужен, чтобы читать
   `Download/PillarsOfEternityMobile`). Включите и вернитесь — игра запустится.
3. Кнопка-шестерёнка открывает меню паузы; в «Настройках игры…» — опции порта: лимит кадров (30 / 60 / 90 / 120,
   меняется сразу), формат картинки (во весь экран / 16:9 с полями), касания как мышь ПК, время удержания для правой
   кнопки, язык игры, счётчик FPS, экранный геймпад.

**Сенсорное управление:** тап — левая кнопка мыши (выбор, ходьба, атака, разговор, любые меню и окна), удержание —
правая кнопка, движение двумя пальцами — сдвиг камеры, щипок — зум, тап двумя пальцами — пауза, два пальца удержать — выбрать весь отряд, тап тремя пальцами — закрыть окно. Если удобнее консольное управление, снимите в
настройках галочку «Касания как мышь ПК» и играйте экранным геймпадом («Экранный геймпад…» в меню паузы: скин,
прозрачность, размер, раскладка). Bluetooth / USB-геймпад тоже работает; пока вы им пользуетесь, экранный пад скрыт.

Сохранения и настройки хранятся в памяти приложения (`Android/data/org.pillars.mobile/files`). Установка новой версии
APK поверх старой их сохраняет; **удаление приложения стирает сохранения.**

## Проблемы / FAQ

**«image: main build id … is not the supported one»** — у вас не обновление v393216 (2.60.00): снимите именно его.

**«no dump files found» / «no prod.keys found»** — проверьте, что файлы лежат в `put-game-files-here` (установка ищет и в
самой папке установки), или перетащите их на `setup.bat`.

**Распаковщик останавливается на ключах или на обновлении** — нужны ключи той консоли, с которой снят дамп, снятые свежим
Lockpick_RCM (`title.keys` — другой файл), а NSP нужно снимать с включённым в nxdumptool *remove console specific data*.

**Установка сразу останавливается из-за места** — на диске с папкой установки нужно около 90 ГБ свободного места:
освободите место или перенесите всю папку установки (вместе с дампами) на диск побольше.

**Вместо игры показывается страница, чего не хватает** — папка лежит не там, где её ищет приложение, или не выдан доступ
к файлам. Проверьте, что путь на телефоне ровно `Download/PillarsOfEternityMobile/RomFS/Data`, разрешите «Доступ ко всем
файлам» на этой странице и проверьте снова. В настройках тоже видно, выдан ли доступ, и есть кнопка в системную настройку.

**Где выбрать язык?** — шестерёнка → «Настройки игры…» → «Язык игры (тексты и озвучка)»; действует со следующего
запуска игры. Формат картинки и режим касаний тоже меняются со следующего запуска, а лимит кадров — сразу.

**Тормозит / телефон греется** — уменьшите лимит кадров в «Настройках игры…» (60 или 30), он меняется сразу.

**Чёрный экран или приложение закрывается** — откройте issue в этом репозитории: модель телефона, версия Android, что
произошло, и приложите всю папку `Download/PillarsOfEternityMobile/logs/`: после падения следующий запуск пишет туда
`crash.txt`; `boot.log` и `logcat.txt` текущего запуска и `boot.prev.log` / `logcat.prev.txt` предыдущего пишутся во
время игры. При проблемах с установкой скопируйте в issue текст из её окна.

Подробно о том, что нужно установке и сколько она идёт: [DEPENDENCIES.md](DEPENDENCIES.md) (англ.). Что она делает по
шагам: `setup.bat --help`.
